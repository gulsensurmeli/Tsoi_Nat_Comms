# Figure 6 plots

This folder contains all the files needed for the plots for Figure 6.

To set up the environment with the appropriate packages to run these scripts, set up the working directory in this folder and run:

```
conda env create -f set_up.yml
conda activate ec_analysis_fig_6
```
**`Quantitative_plots_fig6a-c.ipynb`** file generates plots used in Figure 6 panels a-c.

For panel d, see code in folder **`Figure_10-11_sup`**

The **`master_detailed_comment.csv`** file contains the full information about each neuron’s projection data, soma location, and projection group. It is generated by the **`preprocessing_of_files.ipynb`** file in the Figure 5 folder. Please refer to the README in the Figure 5 folder for more details.

The **`ec_mapseq_data_full.csv`** file contains spike-in-normalised barcode counts from MAPseq data.
