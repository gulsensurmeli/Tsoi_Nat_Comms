# Tsoi_Li_Agboraw_et_al
Submission documents <br>
This folder contains the custom computational scripts, data analysis workflows, datasets and visualization code required to replicate the findings presented in our manuscript.

## Repository Purpose
The code is explicitly mapped to the figures presented in the main text. Each subdirectory within `src/` corresponds to a primary figure panel layout, housing the distinct scripts used to process inputs and output final visual panels.

## Prerequisites & Installation
To set up the computational environment needed to execute these scripts, ensure you have [Python 3.x / R 4.x] installed, then follow these steps:

1. Clone or download the code.
2. Install all required software dependencies as listed in the README files or in the comments at the beginning of the code.

## How to Run the Analysis
To regenerate a specific figure, navigate to its respective directory under `src/` and follow the instructions in the local README file. 

- **Raw Data:** The original source data or large image files will be uploaded to a public domain but can also be shared upon request.
- **Processed Data:** Intermediate datasets generated to run the provided scripts are provided in the corresponding figure folders.
